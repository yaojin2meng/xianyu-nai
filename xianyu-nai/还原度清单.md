# 咸鱼ai画图.dll → Go 重制：功能还原度清单

- 分析目标：`work/unpacked.dll`（原 `咸鱼ai画图.dll` 经 UPX 5.2.1 脱壳，1,803,264 → 5,390,336 字节，ImageBase `0x10000000`）
- 产物：`xianyu-nai.exe`（模块 `xianyu-nai`，Go 1.22，纯标准库，无第三方依赖）
- 方法：仅静态反汇编（易语言 32 位 DLL 无法直接运行取证）；所有结论带 RVA 注释
- 状态：`go build ./...`、`go vet ./...`、`go test ./...`（104 个用例）全绿；NAI / SD / ComfyUI 三条通道均通过假服务器真机端到端

## 交付形态决定（2026-10-19）

**不做 DLL，交付 EXE + OneBot。** 用户已确认此路线。

不做的原因（实测，非推测）：

1. Go 的 `-buildmode=c-shared` 强制外部链接。`CGO_ENABLED=0` 直接报
   `-buildmode=c-shared requires external (cgo) linking, but cgo is not enabled`；
   `CGO_ENABLED=1` 报 `cgo: C compiler "gcc" not found`。
2. 本机无任何 C 编译器。`C:\Program Files`、`C:\msys64`、`C:\MinGW`、`C:\TDM-GCC-32`、
   `scoop`、`AppData\Local` 全量搜索，只找到 Go 自带的 `C:\Program Files\Go\pkg\tool\windows_amd64\link.exe`。
3. 原 DLL 是 **i386**（`Machine=0x14c`，ImageBase `0x10000000`），宿主为 32 位易语言框架，
   必须用 32 位工具链，`GOARCH=386` 纯 Go 可编译但无法产出 c-shared。
4. 导出层（`Init` / `Enable` / `Disable` / `Uninit` / `Setting` / `GetPluginVersion` /
   `_OnEventNT` / `_OnGroupNT` / `_OnPrivateNT` 等 22 个具名导出 + 27 个序号导出）
   尚未实现 C ABI 封送层。

因此改用 EXE + OneBot v11（HTTP 上报 / 正向 WS / 反向 WS 三种接法均已实测）。
功能上三条画图通道完整还原；差异仅在加载方式：原插件由 QQ 框架以 DLL 方式载入，
重制版作为独立进程通过 OneBot 与框架通信。

## 一点五、配置面板（`nai/ui.go`）——原插件 UI 的还原

### 原插件 UI 的真实形态（反汇编实测）

原插件的「设置」不是原生窗口，而是 **WebView2 承载的网页**：

| 项 | 证据 |
|---|---|
| `Setting()` 入口 | `0x100B9A6C`；`_ControlPanelNT` `0x100B7BDE`；`_xyopenControlPanel` `0x100AD66A`，三者都汇到 `0x10090D08` → `0x10090E20` |
| 释放 `edgeview.dll` | 内嵌 PE @ `0x102BC8EC`，名字常量 `0x102BC8C0` |
| 释放 WebView2 安装器 | `0x102BC8D0` = `webview2runtime_win7.exe` |
| 检测 WebView2 Runtime | 失败串 `0x10399FAC`「未检测到 WebView2 Runtime…」 |
| 释放失败串 | `0x10399F00`「edgeview.dll 释放失败，请手动从群文件下载复制到框架根目录」 |
| 页面路径 | `0x10399FFC` = `ui\index.html` |
| 虚拟主机 | `0x1039A1B0` = `http://xianyu.ui/index.html?r=`；`0x1039A298` = `http://xianyu.ui/index.html` |
| UI 版本号 | `[浏览器UI] 版本号`（`0x1039A014`）；下载地址 `[浏览器UI] ui_url`（`0x1039A00C`） |
| 下载失败串 | `0x1039A028`「未能连接授权服务器获取接口文本」 |
| 菜单页 | `ui\menu.html`（`0x102B6698`），渲染到 `图片缓存\菜单.png`（`0x102B66B4`），主机 `http://xianyu.render/render_temp.html?r=`（`0x102B6AC4`） |
| 菜单数据结构 | `menuConfig`（`0x102B66A8`）+ `groups[1..4]`（`0x102B6030`…`0x102B65DC`），每组若干 `{key,name,enabled,notice}` |
| 其它附属页 | `ui\render_temp.html`（`0x102B6AB0`）、`ui\md.html`（`0x102B6FC8`） |

**结论：二进制里没有可提取的 HTML/ZIP**。全盘搜索 `<!DOCTYPE` / `<html` / `<div` /
`createApp` 命中 0（`Vue` 仅 1 处 @ `0x2A0832`），页面是运行时从授权服务器
`ui_url` 下发的。10 个 `RT_DIALOG` 资源全部是易语言运行库自带的（打印设置、
页面旋转、输入框），不是插件 UI。因此**没有原生窗口资源可以还原**。

### 重制版的做法

同一件事换个承载：进程内置 `net/http` 服务托管内嵌页面，浏览器打开；
不需要 WebView2 / edgeview.dll，不联网下载 UI。配置仍落同一份
`咸鱼ai画图.ini`，所以手工编辑 ini 与面板编辑完全等价。

| 接口 | 说明 |
|---|---|
| `GET /` | 内嵌面板页面（无 CDN、无第三方依赖，纯标准库） |
| `GET /api/schema` | 节 / 键 / 类型 / 默认值 / 节名常量 RVA |
| `GET /api/config` | 读 ini 全部节键 |
| `POST /api/config` | 写 ini + 热重载，返回回读结果 |
| `GET /api/status` | 数据目录、ini 路径、SD/Comfy 地址、NAI 模式 |
| `GET /api/presets` | 预设 / 标签 / ComfyUI 工作流清单 |

面板结构由 `UISchema()` 单一数据源驱动，18 个分页的节名与键名逐条来自
对 DLL「读配置项」调用点的实测（`work/allini.txt`，324 处调用）：

| `[点数消耗]` | `0x102B8038` | sd画图 / nai画图 / comfy画图 |
| `[图像审核]` | `0x10025978` | 平台 / 开关 / 阈值 / 处理 |
| `[黑名单功能]` | `0x100A2490` | 6 个 |
| `[nai3设置]` | `0x102B5C14` | key / 官方key / 模式 |
| `[nai3参数]` | `0x102B5B78` | scale / steps / cfg / strength / 默认种子 / 宽度 / 高度 / 采样 / 噪声 / sm / sm_dyn / 全局默认模型 / 负面词条 / 完成后冷却 / 完成冷却模式 |

> NAI 的地址类字段（`nai3api` `naiofficialapi` `nai3_plugin-api` `资源地址`
> `upload-image`）在 DLL 里是从内存 JSON 取值（`0x1005E4B7` 取 `nai3api`，

> 重制版没有下发链路，把它们放进新增的 `[重制版]` 节持久化；
> 面板上单独标「新增」，不冒充原插件行为。

## 二、宿主适配层（不属于 DLL 功能）

原插件是易语言写的 QQ 框架插件 DLL，网络层由框架提供。重制版改用 OneBot v11 对接：

| 接法 | 参数 | 状态 |
|---|---|---|
| HTTP 上报 + HTTP API 回调 | `-onebot -ob-api -ob-listen -ob-path` | 已实测 |
| 正向 WebSocket（框架连进来） | 追加 `-ob-ws`，地址 `ws://<listen><path>/ws` | 已实测 |
| 反向 WebSocket（插件连框架） | 追加 `-ob-ws-reverse ws://host:port/path`，断线 5s 重连 | 已实测 |

帧层按 RFC 6455 自实现：文本帧、分片重组、ping/pong、客户端出帧强制掩码、101 握手与 `Sec-WebSocket-Accept` 校验。**不支持** `wss://`（需前置反向代理）。

## 三、未实现 / 已知差异

1. **DLL 形态**：不做。原因见开头「交付形态决定」。
2. **GBK 互操作**：原插件 ini 按 ANSI(GBK) 读写，重制版统一 UTF-8。语义一致，文件编码不同。
3. **wss://**：需要 TLS 时请用反向代理终止 TLS。
4. **易语言对象布局**：仅用于反汇编取证，重制版不依赖。
5. **原插件 UI 页面**：页面本身由授权服务器下发，二进制内无可提取 HTML；
   重制版用自建 HTTP 面板替代（见「一点五」）。`ui\menu.html` 生成的
   图片菜单未复刻。
6. **界面承载**：原插件用 WebView2 + `edgeview.dll`，重制版用系统浏览器。
7. 上表标注“推定 / 未确认”的 5 处。
