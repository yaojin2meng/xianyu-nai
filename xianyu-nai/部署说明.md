# 部署与使用

产物：`xianyu-nai.exe`（Windows）。功能还原自 `咸鱼ai画图.dll`，以独立进程 + OneBot v11 与 QQ 框架通信。

---

## 一、最短路径（HTTP 上报 + HTTP API）

前提：已有一个支持 OneBot v11 的 QQ 框架（NapCat / LLOneBot / go-cqhttp 等），并记下：

- 它的 HTTP API 地址，例如 `http://127.0.0.1:5700`
- 它的 access_token（没设就留空）

启动：

```powershell
.\xianyu-nai.exe -onebot `
  -ob-api http://127.0.0.1:5700 `
  -ob-listen 127.0.0.1:5701 `
  -ob-path /onebot `
  -data C:\bot\data `
  -comfy-url http://127.0.0.1:8188
```

然后在框架里把**事件上报地址**设为 `http://127.0.0.1:5701/onebot`，格式 `json`。

---

## 二、WebSocket 两种接法

### 正向 WS（框架当客户端，连插件）

在上一节基础上加 `-ob-ws`：

```powershell
.\xianyu-nai.exe -onebot -ob-api http://127.0.0.1:5700 `
  -ob-listen 127.0.0.1:5701 -ob-ws -data C:\bot\data
```

框架侧填：`ws://127.0.0.1:5701/onebot/ws`

### 反向 WS（插件当客户端，连框架）

```powershell
.\xianyu-nai.exe -onebot `
  -ob-ws-reverse ws://127.0.0.1:3001/onebot/v11/ws `
  -data C:\bot\data
```

断线后每 5 秒自动重连，日志会打印
`反向 WebSocket 已连上：...` / `反向 WebSocket 已断开，5 秒后重连`。

> `wss://` 未实现。需要 TLS 时在插件前放一个反向代理做 TLS 终止，代理到本机的 `ws://`。

## 三、三条画图通道怎么配

### NAI

| 参数 | 对应 ini 键 |
|---|---|
| `-key` | `nai3key`（反代 key） |
| `-proxy` | `nai3api`（反代地址） |
| `-official-key` | `naiOfficialKey` |
| `-official-url` | `naiofficialapi` |
| `-mode 官方` / `-mode 反代` | `naiMode` |

### SD（Stable Diffusion WebUI）

| 参数 | 对应 ini 键 |
|---|---|
| `-sd-url` | `[sd设置] 链接` |
| `-sd-user` | `[sd设置] 账号` |
| `-sd-pass` | `[sd设置] 密码` |
| `-ini` | 直接指定 `咸鱼ai画图.ini` 路径，一次读走 `[sd设置]/[sd参数]` |

### ComfyUI

| 参数 | 对应 ini 键 |
|---|---|
| `-comfy-url` | `[comfy设置] 链接` |
| `-comfy-token` | `[comfy设置] Token` |
| `-comfy-ini` | 指定 ini，读 `[comfy设置]/[comfy参数]/[comfy指令]` |

工作流放 `{数据目录}\comfy工作流\<名字>.json`，占位符写 `《提示词》《种子》《宽度》《高度》《步骤》《CFG》《采样器》《调度器》《负面提示词》`，
也可写 `《参数名|默认值》`。

## 三点五、配置面板（UI 界面）

原插件的设置界面是 **WebView2 加载的网页**，不是原生窗口。重制版把同一件事
换成「进程内置的本地 HTTP 面板」，用浏览器打开，不需要装 WebView2 / edgeview.dll，
也不需要联网下载 UI 包。

### 启动

```powershell
# 只开面板改配置（不接 QQ），改完 Ctrl+C 退出
.\xianyu-nai.exe -ui -ui-addr 127.0.0.1:5801 -data C:\bot\data

# 接 QQ 的同时开面板
.\xianyu-nai.exe -onebot -ob-api http://127.0.0.1:3000 -ui -ui-addr 127.0.0.1:5801 -data C:\bot\data
```

控制台会打印：

```
配置面板已启动：http://127.0.0.1:5801/
数据目录：C:\bot\data
```

浏览器打开这个地址即可。`-ui-addr` 省略时默认 `127.0.0.1:0`（随机端口，避免冲突）。

### 面板能改什么

左侧 18 个分页，节名与 `咸鱼ai画图.ini` 的节名**逐字一致**，字段旁标注了 ini 键名：

| 分页 | 对应 ini 节 | 内容 |
|---|---|---|
| 基本 / 类型 | `[基本]` `[类型]` | 主人、机器人 QQ、发送模式、引用、翻译接口、屏蔽词条 |
| 指令 | `[指令]` | 菜单、开启群、关闭群、清晰术、去背景、混淆等通用指令词 |
| 点数限制 / 点数消耗 | `[点数限制]` `[点数消耗]` | 积分开关、基础点数、三条通道单次消耗 |
| 图像审核 | `[图像审核]` | 平台、开关、阈值、命中后的处理方式 |
| 黑名单功能 | `[黑名单功能]` | 被拉黑后仍可使用的功能（填指令名） |
| **nai3设置** | `[nai3设置]` | 模式（官方/反代）、反代 Key、官方 Key |
| **nai3参数** | `[nai3参数]` | scale/steps/cfg/strength/种子/宽高/采样/噪声/sm/sm_dyn/模型/负面词条/冷却 |
| **nai3指令** | `[nai3指令]` | 18 条 NAI 指令词 |
| sd设置 / sd参数 / sd指令 | `[sd设置]` `[sd参数]` `[sd指令]` | SD 链接账号密码、出图参数、10 条指令词 |
| comfy设置 / comfy参数 / comfy指令 | `[comfy设置]` `[comfy参数]` `[comfy指令]` | ComfyUI 链接 Token、出图参数、5 条指令词 |
| 浏览器UI | `[浏览器UI]` | 仅保留版本号，重制版不使用 |
| 重制版（新增） | `[重制版]` | 原插件由授权服务器下发的地址，以及 OneBot 连接参数 |

`[重制版]` 是**重制版新增**的节（面板上带「新增」标记）。原插件的 `nai3api`、
`naiofficialapi`、`nai3_plugin-api`、`资源地址`、`upload-image` 是从授权服务器
拉下来放在内存里的，没有落盘通道；重制版没有这条下发链路，所以由用户填写并
持久化到 `[重制版]`。

### 保存后的行为

点「保存并生效」后：写回 `咸鱼ai画图.ini` → 调用 `Plugin.ReloadFromINI()` →
Nai/SD/Comfy 三条通道的客户端、门禁（积分/审核）、指令词全部立即换成新值，
不需要重启进程。

面板只接受 schema 里声明过的节与键，提交未知节或未知键会被拒绝（HTTP 500 +
错误文本），避免误写整份 ini。

### 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 面板页面（内嵌，无 CDN、无第三方依赖） |
| GET | `/api/schema` | 面板结构：节 / 键 / 类型 / 默认值 / 节名常量 RVA |
| GET | `/api/config` | 读出 ini 全部节键（缺失项用 schema 默认值补齐） |
| POST | `/api/config` | 写入 ini 并热重载，返回回读结果 |
| GET | `/api/status` | 数据目录、ini 路径、SD/Comfy 地址、NAI 模式 |
| GET | `/api/presets` | 已装载的预设、标签、ComfyUI 工作流清单 |

面板默认只监听 `127.0.0.1`。要放到局域网里用，请显式改 `-ui-addr 0.0.0.0:5801`
并自行加防火墙/反向代理鉴权——面板本身没有登录。

### 与原插件界面的差异

| 项 | 原插件 | 重制版 |
|---|---|---|
| 承载方式 | WebView2 + `edgeview.dll` | 系统浏览器 |
| 页面来源 | 授权服务器下发 `ui\index.html` | 编译进 EXE |
| 主机 | `http://xianyu.ui/index.html?r=` | `http://127.0.0.1:<port>/` |
| 图片菜单 | `ui\menu.html` → `图片缓存\菜单.png` | 未复刻（无图床依赖） |
| 落盘 | 同一份 `咸鱼ai画图.ini` | 同一份 `咸鱼ai画图.ini` |

## 四、数据目录里会出现的文件

| 文件 | 用途 |
|---|---|
| `咸鱼ai画图.ini` | 主配置（面板与手工编辑同一份，节名见「三点五」） |
| `seed.ini` | 每用户 SD 种子 |
| `Negative.ini` | 每用户 SD 负面词条 |
| `sd预设列表.json` | SD 预设 |
| `comfy预设列表.json` | ComfyUI 预设 |
| `comfy工作流\*.json` | ComfyUI 工作流绑定 |
| `user_cache.ini` | 每用户选中的 ComfyUI 工作流 |
| `nai3预设列表.json` / `nai3标签列表.json` | NAI 预设与标签 |

> 重制版 ini 统一按 **UTF-8** 读写。原插件是 ANSI(GBK)——若你手头有旧 ini，
> 先用记事本另存为 UTF-8 再放进来，否则中文键名会读不出来。

## 五、CLI 自检命令（不接 QQ 也能验证配置）

```powershell
# 列 NAI 模型表
.\xianyu-nai.exe -models

# 列 SD / VAE / LoRA
.\xianyu-nai.exe -sd-models -sd-url http://127.0.0.1:7860
.\xianyu-nai.exe -sd-vaes   -sd-url http://127.0.0.1:7860
.\xianyu-nai.exe -sd-loras  -sd-url http://127.0.0.1:7860

# 列 ComfyUI 工作流绑定
.\xianyu-nai.exe -comfy-models -comfy-url http://127.0.0.1:8188 -data C:\bot\data

# 只看 ComfyUI 最终提交体，不发送
.\xianyu-nai.exe -comfy-dump -comfy-url http://127.0.0.1:8188 -data C:\bot\data -comfy-prompt "1girl, solo"

# 真出一张图
.\xianyu-nai.exe -comfy-draw -comfy-url http://127.0.0.1:8188 -data C:\bot\data -comfy-prompt "1girl, solo"

# 只看 SD 请求体
.\xianyu-nai.exe -sd-dump -sd-url http://127.0.0.1:7860 -sd-user u -sd-pass p
```

## 六、指令一览

| 通道 | 指令 |
|---|---|
| NAI | `nai画图` / `nai3指令` / `nai查看模型` / `nai查看预设` / `nai上传预设` / `nai删除预设` / `nai导演`（emotion/declutter/colorize/sketch/lineart）/ `nai积分` |
| SD | `sd画图` / `sd查看模型` / `sd查看vae` / `sd查看lora` / `sd查看预设` / `sd上传预设` / `sd删除预设` / `sd种子` / `sd查看负面` / `sd修改负面` |
| ComfyUI | `comfy画图` / `comfy查看模型` / `comfy查看预设` / `comfy上传预设` / `comfy删除预设` |

聊天内联参数：

- NAI / SD：`#种子123` `#步数30` `#CFG5` `#宽1024` `#高1024` 等
- ComfyUI：`#模型2`（切工作流）`#步骤28` `#CFG5.5` `#负面提示词:blurry` `#任意参数名:值`
